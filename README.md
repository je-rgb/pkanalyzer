# PK Analyzer
### MPEG-2 Transport Stream Analysis Tool

**PK Analyzer는 영상·음성 전송 데이터인 TS 파일을 분석하여 패킷의 구성과 오류 정보를 확인할 수 있는 Python 기반 분석 도구입니다.**

영상이 정상적으로 전송되려면 영상과 음성 데이터가 정해진 형식에 따라 전달되어야 합니다. PK Analyzer는 이러한 전송 데이터를 패킷 단위로 분석하고, 각 패킷이 어떤 데이터를 전달하는지와 데이터에 이상이 있는지를 GUI에서 확인할 수 있도록 개발했습니다.

## 📌 1. 프로젝트 소개

### PK Analyzer란?

방송이나 영상 전송에 사용되는 데이터는 작은 단위의 패킷으로 나뉘어 전달됩니다. 이때 사용하는 대표적인 형식 중 하나가 MPEG-2 Transport Stream(TS)입니다.

TS 파일에는 영상과 음성 데이터뿐 아니라 프로그램 구성 정보와 전송에 필요한 제어 정보도 포함됩니다.

하지만 TS 파일을 일반적인 텍스트 편집기로 열면 대부분의 내용을 쉽게 이해하기 어렵습니다. 패킷 내부의 데이터를 해석하고, 패킷 사이의 관계를 파악해야 파일의 구조와 이상 여부를 확인할 수 있기 때문입니다.

**PK Analyzer는 이 과정을 자동화하여 복잡한 TS 데이터를 사람이 이해하기 쉬운 분석 결과로 변환하는 도구입니다.**

### 개발 목적

- TS 파일의 패킷 구조와 스트림 구성을 쉽게 확인합니다.
- PID별 패킷 분포와 프로그램 정보를 분석합니다.
- 패킷 동기화 및 연속성 관련 이상을 탐지합니다.
- 분석 결과를 GUI에 표시하여 데이터 확인 과정을 간소화합니다.

## 🔎 2. TS 파일은 어떻게 구성되어 있을까요?

PK Analyzer의 분석 과정을 이해하려면 먼저 TS 파일의 기본 구조를 알아야 합니다.

### 2.1. 패킷(Packet)

패킷은 데이터를 일정한 크기로 나누어 전달하는 기본 단위입니다.

MPEG-2 TS의 일반적인 패킷은 **188바이트**로 구성됩니다. 각 패킷에는 데이터를 식별하기 위한 헤더와 실제 전송 데이터가 포함될 수 있습니다.

PK Analyzer는 TS 파일을 패킷 단위로 읽고, 각 패킷의 헤더에 담긴 정보를 분석합니다.

### 2.2. PID(Packet Identifier)

PID는 패킷이 어떤 종류의 데이터 스트림에 속하는지 구분하기 위한 식별 번호입니다.

하나의 TS 파일에는 영상, 음성, 프로그램 정보 등 여러 종류의 데이터가 함께 들어갈 수 있습니다. PID를 이용하면 이 데이터들을 구분할 수 있습니다.

예를 들어 다음과 같은 결과를 얻을 수 있습니다.

| PID | 의미 |
|---|---|
| 영상 PID | 영상 데이터를 전달하는 패킷 |
| 음성 PID | 음성 데이터를 전달하는 패킷 |
| PMT PID | 프로그램 구성 정보를 전달하는 패킷 |
| 기타 PID | 그 밖의 정보 또는 별도 데이터 스트림 |

위 표는 PID의 역할을 설명하기 위한 예시입니다. 실제 PID 번호와 역할은 파일의 프로그램 구성에 따라 달라집니다.

PK Analyzer는 PID별 패킷 수를 집계하여 어떤 데이터가 얼마나 포함되어 있는지 파악할 수 있도록 합니다.

### 2.3. PAT와 PMT

PAT와 PMT는 TS 파일에 어떤 프로그램과 미디어 스트림이 포함되어 있는지 알려주는 정보입니다.

- **PAT(Program Association Table):** 프로그램과 해당 프로그램의 PMT 위치를 연결합니다.
- **PMT(Program Map Table):** 프로그램에 포함된 영상·음성 스트림과 각 스트림의 PID 등을 알려줍니다.

쉽게 말해 PAT가 프로그램 정보를 찾는 출발점이라면, PMT는 해당 프로그램이 어떤 스트림으로 구성되어 있는지 알려주는 역할을 합니다.

PK Analyzer는 이 정보를 분석하여 프로그램과 영상·음성 스트림 사이의 관계를 파악합니다.

### 2.4. Sync Byte와 Continuity Counter

패킷을 올바르게 읽고 전송 데이터의 연속성을 확인하려면 패킷의 시작 위치와 순서를 확인해야 합니다.

- **Sync Byte:** 패킷의 시작을 식별하는 값입니다. 일반적인 TS 패킷에서는 `0x47`을 사용합니다.
- **Continuity Counter(CC):** 동일한 PID의 패킷에서 데이터 연속성을 확인하는 데 사용하는 카운터입니다.

패킷 시작 위치가 맞지 않거나 CC 값이 예상한 규칙과 다르면 데이터에 이상이 있을 가능성을 확인할 수 있습니다.

PK Analyzer는 이러한 정보를 검사하여 동기화 문제와 연속성 관련 오류를 파악할 수 있도록 합니다.

TS 파일을 패킷 단위로 읽고 헤더에 포함된 주요 정보를 추출합니다.

분석 결과를 통해 각 패킷의 구조와 식별 정보를 확인할 수 있습니다.
